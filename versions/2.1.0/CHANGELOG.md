# Games Widget 2.1.0

- **Mac-inspired window controls**: The toolbar buttons are now color-coded rounded squares — the compact/restore button is yellow, the close button stays red, and all controls keep smooth hover/active transitions.
- **Performance Mode button**: Restyled with a vibrant blue gradient theme and a soft glow on hover for a distinct, energetic identity.
- **Settings button**: Replaced the emoji glyph with a crisp SVG gear icon styled in a premium indigo/violet gradient (`#6366F1`).
- **Layout toggle**: The vertical/horizontal performance layout switch is now green, including an active-state glow while horizontal mode is engaged.

**Compared with:** [2.0.4](../2.0.4/CHANGELOG.md). Focused on a cohesive color-coded control system and polished toolbar visuals.
