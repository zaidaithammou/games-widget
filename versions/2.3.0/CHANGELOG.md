# Games Widget 2.3.0

- **Accordion settings**: Cover Art Style, Game Library Platforms, Themes, and User Groups are now clean collapsible drop-down sections — collapsed by default, with smooth expand/collapse animation.
- **Exclusive open behavior**: Only one accordion section can be open at a time; opening a new section automatically collapses the previous one. The open section is remembered between settings visits.
- **Theme switcher with 5 templates**: New Themes section offering Midnight (current dark), Clean Light, Midnight Cyber Blue, Nordic Frost, and Emerald Dusk — each with distinct surfaces, accents, and glow treatments.
- **CSS variable architecture**: The entire UI palette (backgrounds, surfaces, fields, text, accents, scrollbars, performance cards) now runs through theme variables, so all five themes restyle the widget coherently — including the performance overlay.
- **Uniform overlay transparency**: All five themes now share the same ~26–30% see-through background opacity, so the widget behaves consistently as a desktop overlay in every theme (previously Cyber/Nordic/Emerald were noticeably more opaque, and Light was fully opaque).
- **Styling retention**: All previous button rules preserved — rounded squares, uniform sizes, expanded hit-areas, neutral defaults, and hover-only color coding (red close, yellow compact, green layout toggle, blue performance, indigo settings).

**Compared with:** [2.2.0](../2.2.0/CHANGELOG.md). Major settings UX modernization plus a full multi-theme system.
