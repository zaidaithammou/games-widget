# Games Widget 1.0.0

First distributable Electron desktop-widget build.

- Added the frameless, always-on-top Windows widget, system-tray controls, saved window placement, and header dragging.
- Added installed-game discovery for Steam, Epic Games, and GOG, with Steam artwork lookup for the library.
- Added the initial game-library views, filtering/sorting controls, and a compact minimize mode.

**Snapshot:** `source/` contains the app files and assets recovered from this installer's packaged Electron archive. This is the initial available build, so there is no earlier packaged snapshot to compare against.
