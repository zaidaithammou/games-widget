# Games Widget 1.1.0

- Added expanded-window limits of 520 x 460 through 960 x 540 pixels and constrained the widget to the display's usable area while moving or resizing.
- Made the full header draggable while leaving its controls clickable.
- Added animated folders for Steam, Epic Games, GOG, Unassigned, and user-created groups, with actions for assigning games to custom groups.

**Compared with:** [1.0.9](../1.0.9/CHANGELOG.md). The recovered main-process bounds logic and renderer folder UI confirm these changes. The AI upscaler was still present in this build.
