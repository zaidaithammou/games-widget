# Games Widget 1.0.8

- Simplified the view selector to **Discs** and **Icons**; the former wallpaper presentation became Icons, and the extra icon mode was removed.
- Standardized the Icons artwork frame and its dark letterboxing/border.
- Improved Epic game launching with Epic deep links and recovery of launch identifiers from installed-game manifests, with an installed-path fallback.
- Refined centering of the Remove control.

**Compared with:** [1.0.7](../1.0.7/CHANGELOG.md). The recovered UI and launch code confirm the view cleanup and Epic launch flow.
