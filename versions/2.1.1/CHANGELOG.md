# Games Widget 2.1.1

- **Hover-only accent colors**: Window and toolbar buttons now keep the standard neutral dark-theme styling at rest; the color palette activates only on hover.
- **Traffic-light hovers**: Close turns red, the compact/restore button turns yellow, and the performance layout toggle turns green on hover.
- **Action button hovers**: Performance Mode lights up with a vibrant blue gradient, and Settings uses the indigo/violet `#6366F1` accent — both with soft glows.
- **Complete hover coverage**: The performance panel's minimize and exit buttons now have matching hover/active states (yellow and red respectively), and duplicate style rules were cleaned up.

**Compared with:** [2.1.0](../2.1.0/CHANGELOG.md). Corrects the always-on accent colors into hover-only activation and fills in missing hover states.
