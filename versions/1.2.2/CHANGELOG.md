# Games Widget 1.2.2

- **Fixed settings persistence**: Platform checkboxes (Steam, Epic Games, GOG, Xbox, Battle.net, Ubisoft Connect, EA App) are now saved when clicking Save in Settings and restored when reopening the widget. Previously, these checkboxes were not being persisted across sessions.

**Compared with:** [1.2.1](../1.2.1/CHANGELOG.md). Fixes platform settings persistence in the Settings panel.
