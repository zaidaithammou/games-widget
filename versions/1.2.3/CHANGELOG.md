# Games Widget 1.2.3

- **Fixed Performance Mode dependency links**: The overlay now keeps the taller layout when RTSS or MSI Afterburner download links are shown instead of snapping back to the clean-state height and hiding the buttons.
- **Larger Performance Mode window**: The vertical performance overlay is slightly larger so the FPS hint and dependency links remain visible.
- **Horizontal Performance Mode layout**: Added a hamburger-style button at the top-left of Performance Mode to switch the FPS, CPU, GPU, and RAM cards between vertical and horizontal arrangements.

**Compared with:** [1.2.2](../1.2.2/CHANGELOG.md). Fixes Performance Mode sizing for missing monitoring dependencies and adds a vertical/horizontal layout toggle.
