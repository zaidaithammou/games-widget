
# Project Contributions

## Development

Games Widget is an independently developed project focused on providing a lightweight Windows desktop companion for organizing and launching installed PC games.

The project was developed through independent research, experimentation, and practical implementation.

## AI-Assisted Learning

AI tools were used during development as learning and research assistants.

Their use included:

- Understanding Electron and its architecture.
- Learning how Electron interacts with HTML, CSS, and JavaScript.
- Exploring application structure and desktop functionality.
- Understanding development concepts and troubleshooting issues.
- Exploring possible improvements and feature ideas.

AI assistance was primarily used to support learning and problem-solving throughout development.

## Project Ownership

The project is independently maintained by its developer.

All final implementation decisions, project direction, modifications, and maintenance remain the responsibility of the project developer.

AI tools are acknowledged as learning and development assistance, not as project owners or human contributors.
