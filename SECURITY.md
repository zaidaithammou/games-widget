
# Security Policy

The security of Games Widget and its users is important.

## Supported Versions

Security updates are intended for the latest published version of Games Widget.

Older versions may not receive security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately.

Use GitHub's Private Vulnerability Reporting feature:

1. Open the Games Widget repository.
2. Navigate to the Security tab.
3. Select Report a vulnerability.
4. Describe the issue and provide steps to reproduce it.

Please include:

- A description of the vulnerability.
- The affected application version.
- Steps to reproduce the issue.
- Relevant technical details.

## Important

- Do not disclose vulnerabilities through public Issues.
- Do not publish exploit code or sensitive information before the issue has been reviewed.
- Allow the maintainer reasonable time to investigate and address the report.

## Response

Reports will be reviewed as soon as reasonably possible.
